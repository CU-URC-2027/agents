# CU-URC-2027 rover project context

The canonical project repository is the private GitHub repository
`CU-URC-2027/rover-project`. Read it through the connected GitHub integration
at the current `main` revision. A local clone may be useful for user-authorized
editing, but it is not the source of truth for research or design advice.

## Read order

1. `AGENTS.md` for project instructions and evidence boundaries.
2. `docs/requirements/master-requirements.md` for derived team requirements.
3. Relevant files under `docs/architecture/` for system decisions and models.
4. Relevant files under `docs/research/` for prior evidence and open questions.
5. `docs/source/University Rover Challenge Rules 2026.pdf` and
   `docs/source/urc-website-sources.md` for
   authoritative competition material and official web sources.

The rulebook governs competition rules. The requirements register records
derived, proposed, or approved team requirements; it does not replace the
rulebook. Architecture and research documents supply context but do not
override either of those sources.

When reporting, identify the GitHub revision or file link that was read. Flag
any conflict between a current rulebook source and a derived requirement for
team review instead of resolving it silently.
